> **Opening question:** Could a reader trace this image back to the map, indicator, dataset, date, and view you used?

## Planned learning sequence

1. Identify the map author, host platform, data publisher, dataset, and indicator.
2. Record the selected geography, filters, time period, access date, and stable URL when available.
3. Write a caption stating what the figure shows and why it matters to the argument.
4. Create a source note using the required course or publication style.
5. Check reuse, licensing, and attribution requirements.

## Critical pause

Whose labor and data collection disappear when only the dashboard brand or screenshot URL is credited?

## Planned checkpoint

Learners produce a caption and citation that distinguish interface, visualization, and underlying data sources.
