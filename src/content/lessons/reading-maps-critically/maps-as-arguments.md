> **Opening question:** If this map could speak one sentence, what would it ask you to believe?

## Planned learning sequence

1. Describe the visible pattern without explaining it.
2. State the map's implied or explicit claim.
3. Identify the data and comparison supporting that claim.
4. Examine how title, extent, scale, categories, and color strengthen it.
5. Separate association, interpretation, and causal explanation.

## Critical pause

What alternative framing, denominator, time period, or boundary might support a different argument?

## Planned checkpoint

Learners complete: “The map argues..., using..., but it cannot establish....”
